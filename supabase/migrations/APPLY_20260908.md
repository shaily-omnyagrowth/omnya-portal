## Rolling back

Nothing here is destructive. If the columns must go:

```sql
BEGIN;
DROP INDEX IF EXISTS idx_campaigns_share_token;
ALTER TABLE campaigns
  DROP COLUMN IF EXISTS share_token,
  DROP COLUMN IF EXISTS share_enabled,
  DROP COLUMN IF EXISTS share_created_at;
COMMIT;
```

Leave `start_date` alone: it already existed in production before this
migration, and `client_safe_campaigns` (20260918) selects it.
